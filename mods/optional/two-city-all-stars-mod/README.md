# 双城全明星对战

陈留曹操、许昌刘备；每方君主另带 23 名文武（24 vs 24 全明星阵容）。两城同等初始资源与城防、各六府，屏蔽界外城池与关隘，完整保留原生地形、通行与建设规则。仅在主菜单启用，开始新局。

版本 `0.2.0`，内部 ID `two-city-all-stars-mod`。本目录属于 `optional` 分组。

从仓库根目录使用 `-Target mods -Mod two-city-all-stars-mod -ScenarioFile '<原版 CE 剧本01>'` 构建。原始剧本由使用者本地提供，生成资产只放在 build/。
