# 优化伴侣

精细专家模式调整邻接加成及手动战法；提供规则、游戏加速、官职、府官、报告演出、立绘及看海势力接管。上限、阵型、异族编辑及势力颜色由「增强设定与编辑」提供。

版本 `0.2.0`，内部 ID `companion-mod`。本目录属于 `default` 分组。

从仓库根目录构建与打包：

```powershell
./build.ps1 -Target mods -Mod companion-mod -Tests -ArtifactRoot build/companion-mod
```
