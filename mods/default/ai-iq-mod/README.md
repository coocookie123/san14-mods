# 电脑智商优化

面向电脑势力的战术与外交AI增强：优化攻城阵型配兵、动态同盟与敌对主敌评估、智能水域防御调度、应急增援重调以及敌方攻城器械时间窗截击及电脑施政自动排序。

设置第一页为「常规」，包含两个默认关闭的独立开关：

- **降低电脑官职评定频率**：开启后从每月改为每六个月，仅在每年一月、七月月初按原条件评定；关闭恢复原版。玩家手动任命和优化伴侣加权排序保持原有行为。
- **电脑和军团99命令书**：从优化伴侣移入。原版每旬发放时，电脑势力和玩家委任军团获得99本，玩家直辖军团按原版发放，之后正常扣费。当前适用于简中传承版。旧启用偏好由配套 Host 迁移，已有 AI 设置优先。

原有六项设置在第二页「策略优化」，显示原文保持。两项开关均需要配套 GameAdapter。

版本 `0.2.1`，内部 ID `ai-iq-mod`。本目录属于 `default` 分组。

从仓库根目录构建与打包：

```powershell
./build.ps1 -Target mods -Mod ai-iq-mod -Tests -ArtifactRoot build/ai-iq-mod
```
