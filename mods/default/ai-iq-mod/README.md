# 电脑智商优化

面向电脑势力的战术与外交AI增强：优化攻城阵型配兵、动态同盟与敌对主敌评估、智能水域防御调度、应急增援重调以及敌方攻城器械时间窗截击及电脑施政自动排序。

版本 `0.2.1`，内部 ID `ai-iq-mod`。本目录属于 `default` 分组。

从仓库根目录构建与打包：

```powershell
./build.ps1 -Target mods -Mod ai-iq-mod -Tests -ArtifactRoot build/ai-iq-mod
```
