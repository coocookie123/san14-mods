# 增强设定与编辑

增强设定与编辑：武将基础能力编辑、异族编辑、属性与功劳上限、五档城市、14阵型、官爵军情与雇用上限、势力颜色。支持全局默认和局内恢复。9个有效个性与额外个性编辑（实现中），暂不可操作。

版本 `0.2.0`，内部 ID `enhanced-settings-mod`。本目录属于 `default` 分组。

从仓库根目录构建与打包：

```powershell
./build.ps1 -Target mods -Mod enhanced-settings-mod -Tests -ArtifactRoot build/enhanced-settings-mod
```
