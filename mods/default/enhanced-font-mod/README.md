# 增强字体

通过 Host 的文字渲染服务改善文字缓存清晰度，保持界面原有大小。在设置中切换“增强文本分辨率”，修改后重启游戏生效。作者：年糕（点击姓名打开原帖）。贡献者：清都jsl（点击姓名打开主页；负责 SDK 接入与移植）。

版本 `1.0.0`，内部 ID `enhanced-font-mod`。本目录属于 `default` 分组。

从仓库根目录构建与打包：

```powershell
./build.ps1 -Target mods -Mod enhanced-font-mod -Tests -ArtifactRoot build/enhanced-font-mod
```
