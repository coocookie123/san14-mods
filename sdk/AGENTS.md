# SAN14 Mod SDK

- SDK 定义语义 C ABI，不依赖管理器源码、适配源码或具体 Mod。
- 保持 Host ABI v1 已有前缀及内嵌表偏移；新增能力只能在兼容尾部追加，配套 struct_size 检查。
- 提供读取快照、语义命令和不透明句柄，普通接口不新增游戏地址或原生结构布局。
- 改接口时同步 schema、示例与受影响插件；使用 `tools/build_plugin.ps1` 指定 ProjectRoot、SdkRoot 和 CompilerRoot 验证真实调用方。
- 普通 Mod 开发者使用本 SDK 与管理器运行包即可开发，不需要管理器核心源码。

## 上传与隐私

- 收到可执行的缺陷／功能反馈时，先在维护者指定的共享反馈清单登记，再实施；本机SAN14管理器、SDK、Mod和共享MCP跨分仓共用同一清单，不另建重复记录。结束时补各组件版本、验证、安装、验收和发布状态；共享清单不上传。
- 本目录属于 san14-mods 公共源码仓；真实内存适配实现只保存在独立私有 GameAdapter。
- 提交前检查工作文件和 Git 暂存内容，不提交个人信息、凭据、本机绝对路径、日志、存档、游戏文件、转储、研究材料或开发过程记录。
- 游戏地址、RVA、结构偏移、Hook 实现与生成地址表保留在管理器的本地适配目录；不放入 SDK 或功能插件源码。
- 提交作者和提交者均使用 GitHub 用户名及已验证的 GitHub noreply 邮箱，禁止继承本机个人邮箱。
- 只运行直接相关测试；公共 ABI、生命周期与 Hook 变更补充集成验证。纯文档变更无需编译或安装。区分构建、离线测试、安装与实机验收。
